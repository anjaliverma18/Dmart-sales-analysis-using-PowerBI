# 📊 Dmart-sales-analysis-using-PowerBI

📌Project Overview

this power BI dashboard analyses D-Mart revenue, customer behaviour, payment and operations, and trends.

🚀 Features

\- Total revenue
\- sales by category
\- age-wise distribution
\- ship-mode efficiency
\- cancellation rate
\- payment method analysis

\## 🛠 Tools Used

\- Power BI

\- Excel


\## 📊 Key Insights

\- total revenue generated 16.95M

\- local category contributed highest

\- customers aged 55+ placed orders in large amount

\- priority ship-mode has fastest delivery

\- cancellation rate of orders is 7.14%

\- online mode payment contributed 95% to revenue generation
